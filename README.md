# ANACHRONISM — тестовая веб-версия

Здесь будет публиковаться **только собранная веб-игра** «Телефон Распутина», созданная в приватном репозитории `anachronism`.

- **Исходники игры:** остаются приватными в `dmitryandreyanov-create/anachronism`.
- **Этот репозиторий:** публичная папка `docs/` для GitHub Pages с HTML, JavaScript и игровыми изображениями. Содержимое страницы и картинки открыты всем.
- **Адрес после успешной публикации:** https://dmitryandreyanov-create.github.io/anachronism-preview/
- На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».

Включить один раз: **Settings → Pages → Deploy from a branch → main /docs**. Первую готовую сборку автоматически запишет workflow из приватного `anachronism`, когда его владельцем будет настроен ограниченный секрет `ANACHRONISM_PREVIEW_TOKEN`.

Пока `docs/` содержит только файл `.nojekyll` и не содержит `index.html`, **публичная игра ещё не развёрнута**.
